# Внутренний демо-прототип Labor Market Radar для практики 1С

## Что это

Это локальный HTML-прототип будущего внутреннего продукта.

Он показывает, как внешний рынок труда может сверяться с внутренней ситуацией практики 1С:

```text
внешний radar_snapshot.json
+ демо-слой практики 1С
-> внутренний дашборд
```

## Важно

Сейчас прототип работает только на вымышленных данных.

Реальные внутренние данные практики 1С нельзя публиковать на GitHub Pages и нельзя коммитить в Git.

## Откуда берутся данные

Внешний рынок:

```text
../../data/current_radar/radar_snapshot.json
```

Демо-данные практики 1С:

```text
../../data/internal_1c_demo/internal_1c_snapshot.json
```

Файл `internal_1c_snapshot.json` содержит только вымышленные данные и нужен для проверки механики интерфейса.

## Как открыть

Из корня проекта запустить:

```text
Открыть внутренний дашборд 1С.cmd
```

Файл поднимет локальный сервер и откроет страницу в браузере.

Открывать `index.html` напрямую через `file://` не рекомендуется, потому что браузер может заблокировать загрузку JSON.

## Что показывает дашборд

- общий вывод по практике 1С;
- карточки краткой оценки;
- сверку внешних сигналов и внутренних фактов;
- статус сверки: `подтверждается`, `расходится`, `недостаточно данных`, `ранний внутренний сигнал`;
- что проверить;
- что делать;
- реперные точки планирования;
- ограничения демо-режима.
